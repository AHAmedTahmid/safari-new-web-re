THE ISSUE WITH GITHUB ACTIONS AUTO-DEPLOY
======================================================================
The "Deploy to production" workflow (.github/workflows/deploy.yml)
failed during the rsync-over-SSH step with:

  ***@***: Permission denied (publickey,password).
  rsync error: unexplained error (code 255) at io.c(232)

Root Cause:
The private key in GitHub Secrets (SSH_PRIVATE_KEY) is valid, but the
VPS is rejecting it because the matching public key is not yet present
in ~/.ssh/authorized_keys for the deploy user on the server.
